These are **inventory counts**, not licensed production imports. The original PDF's declared 653 pages and 160 references are not byte-verified against the HTML. FLELex and other externally sourced data retain their own licenses. No cross-source content is silently assumed redistributable.

Every U1 record receives a namespaced, revision-qualified ID generated by `sourceId(source,kind,localId)`. The pin is in the identity, not only in a mutable display label. Source positions are **not** assertions about the upstream lesson titles, CEFR week, sequencing, objectives, exercises, or mastery.

## Working features

- Lazy `#course` route with 60 accessible selectable, pinned source positions, per-position provenance and native Learn handoff.
- Lazy `#grammar` route with nine original A1/A2 microguides and ungraded recall; no content from the rights-gated 72-concept legacy corpus.
- Pure lexical `crosswalkWithLosses`: preserves accented distinctions, one-to-many collisions, unmatched strings, missing sense/POS, unused targets, and **zero verified sense equivalences**. All apparent matches remain candidate-only and require manual bilingual sense review.
- Explicit JSON-file preflight for both legacy applications. Inspect only after a file selection. Limits are 5 MiB, 25,000 visited nodes, depth 32, and array length 15,000. It does not read application storage, upload files, parse a foreign origin's storage, modify records or translate old intervals into FSRS.
- Native `#learn`, `#review` and their progress authority remain unchanged. No learner-state migration occurs.

## Focused verification

`npm run test:vnext:u1` checks source identity, source rights, all 60 course slots, nine original grammar records, lexical loss cases and adversarial migration exports. It is included in the existing `qualify:vnext` chain. P37G browser acceptance covers course route navigation, 60 positions, preflight success/failure, original grammar recall, mobile/browser project matrix and round-trip navigation.

Build size continues to be checked by `npm run verify:vnext:dist` with the existing 48 kB initial shell budget; U1 imports the two new feature modules lazily. New source modules are not bundled into the initial Home payload.
