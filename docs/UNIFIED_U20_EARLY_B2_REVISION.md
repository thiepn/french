`u20-material.ts` extends the existing connected reading index from 147 to **162 original B1/B1+ readings** and delegates prior Read, Listen, sources, three Write modes and ungraded oral models without new engines.

The existing `app/src/routes/u6-a1-panel.ts` has a new direct **Early B2 revision** level jump and a new U20 sequence heading. The existing six-stage Course is still **Understand → Vocabulary → Read → Listen → Recall → Write**, and the U20-specific independent revision UI lives **inside the existing Write stage**, not a new workflow or progress authority:

1. Each of the **15 U20 scenarios** has three **original context-specific revision prompts** (`u20-revision-guides.ts`) on source attribution, claim repair and credible counterarguments.
2. Learners select one of the existing three real independent writing modes, author a full French response, then **capture the earlier draft**.
3. They revise in the same editor and display their **earlier and current versions side-by-side**, with the original source-specific prompts and models available.
4. A capture can be discarded independently. Both earlier and current drafts exist **only in page-memory Maps**, scoped by existing lesson ID + writing mode. The client does not grade correctness, persist in Account, create revision authority or access personal academic records.
5. A compact responsive `unified-u20.css` styles this comparison for mobile and desktop, with clear text and keyboard-native controls.
