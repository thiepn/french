## Limitations and trust boundaries

- No new original historical French source, complete universal dictionary, independent external media recording, new exam blueprint, CEFR certification or automatic proficiency tracking.
- New authored corrections are pedagogical and intentionally **not quoted as original dialogues**; underlying original witnesses are available separately with actual original source/revision locators.
- A source excerpt is an attributed statement, not guaranteed factual truth. Claim-category selection and source inference remain learner-reviewed.

- Drafts are retained **within this mounted page only**; reload/unmount discards them. First-version captures are local text snapshots, not persistent revision history. No automatic result transport across workspaces.
- Reported oral preparation is a writing/speaking prompt; U36 has no microphone, recorded pronunciation recognition or verified language skill score.
